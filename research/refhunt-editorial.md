# Reference Hunt — Out-of-Domain Elite Editorial (for Develop-HTA)

Date: 2026-08-11
Angle: out-of-domain but visually elite, SERIOUS editorial sites whose GEOMETRY + TYPOGRAPHY transplant onto a health-policy / HTA org and still read credible. No flashy motion. All URLs verified LIVE via WebFetch on 2026-08-11.

Target org: Develop-HTA — health-policy / HTA research non-profit. Palette navy/teal/green, medical + Africa motif. No real photography yet. Audience: ministries, hospitals, donors.

---

## 1. Stripe Press — https://press.stripe.com  (verified live via WebFetch)
- Elite/custom signature: A book publisher's site built like a printed book — text-forward, serif hierarchy, no hero image, wordmark + one-line manifesto ("Ideas for progress") carries the top. Reads as authored, not templated.
- CRAFT SIGNATURE TO STEAL: the **object-as-hero** move — instead of a stock photo, the site treats the book *cover* (a designed rectangular artifact) as the visual anchor, set on a calm neutral field with generous whitespace. The "asset" is a piece of typography/graphic, not a photograph. Also: strict two-tier type scale (big title / small meta), editorial serif for authority, color enters ONLY through the covers.
- Register fit: Excellent. Scholarly, restrained, intellectual — exactly the "serious ideas org" tone. Zero gimmickry.
- Adaptation for Develop-HTA (no photos): Replace book covers with **designed report/brief "covers"** (a navy or teal rectangle, title set in your serif, a small brand mark, one geometric motif) as the hero objects. Evidence outputs (reports, HTA guidance, briefs) become the imagery. Africa/medical motif lives as a single line-graphic on each "cover", not a photo.

## 2. Our World in Data — https://ourworldindata.org  (verified live via WebFetch)
- Elite/custom signature: A research/evidence org that looks premium with ZERO photography — leads with hard numbers ("14,049 charts", mission line) and uses its own data visualizations as the entire visual language.
- CRAFT SIGNATURE TO STEAL: **chart-thumbnail-as-hero** and **stat-led opening** — the first thing you see is a mission sentence + big counters, then cards whose "images" are actual line/area charts. The data IS the art direction. Clean sans-serif, ample whitespace, credibility signalled by attribution + update dates.
- Register fit: Perfect — this is the exact register Develop-HTA needs (research/data/evidence, donor-credible). The single best "how does a text-and-evidence org look premium without a photo budget" proof point.
- Adaptation for Develop-HTA: Directly transplantable. Open with a mission line + a row of hard counters (countries supported, assessments delivered, guidelines shaped). Use branded charts (navy/teal/green series) as the recurring visual motif; each program card carries a small chart or Africa-map micro-viz instead of a photo.

## 3. Works in Progress — https://worksinprogress.co  (verified live via WebFetch)
- Elite/custom signature: Stripe-designed progress-studies journal; magazine-grade modular grid with a confident featured-essay hero ("Every disease is a policy failure") and topic-sectioned cascade. Feels like a designed publication, not a CMS.
- CRAFT SIGNATURE TO STEAL: **the featured-essay editorial grid** — one large spotlight article (bold headline, big cover) over a cascading multi-column grid organized by topic (Science / Biotech / Cities). Strong headline typography does the heavy lifting; the grid rhythm (1 big + many small) creates hierarchy without decoration.
- Register fit: Strong and serious, thought-leadership register. Caveat: it leans on distinctive cover imagery per article — so steal the GRID + headline system, not the photo dependence.
- Adaptation for Develop-HTA: Use the 1-big-plus-grid layout for a "Insights / Evidence" section. Replace each cover image with a **generated geometric/illustrated cover** (navy/teal gradient + medical-line or Africa-outline motif) so the grid stays photo-free. Headline typography is where the premium lives.

## 4. Collab Fund — https://collabfund.com  (verified live via WebFetch)
- Elite/custom signature: A venture fund that reads like an essayist — restrained modular grid, a bold plain-language hero statement ("backs entrepreneurs pushing the world forward"), credibility carried by text + portfolio marks rather than imagery.
- CRAFT SIGNATURE TO STEAL: **manifesto-hero + logo/mark field** — a single confident sentence as the hero (no image), then trust built from a tidy grid of partner marks. Minimalist, whitespace-heavy, finance-serious. Shows how a values-driven org states its thesis in one typographic line.
- Register fit: Very good — sober, confident, "serious money" credibility. No flash. Reads institutional.
- Adaptation for Develop-HTA: Use the one-sentence typographic hero for the mission ("We build the evidence systems health ministries decide with"). Swap the portfolio-logo field for a **partners/funders + ministries mark row** (donor and institutional logos = instant credibility, no photography needed). Navy ground, teal accent on the key phrase.

---

### Recommendation
For a text-and-evidence org with navy/teal/green and no photos, **Our World in Data** is the closest register+method match (chart-as-art, stat-led, donor-credible), and **Stripe Press** is the best craft ceiling to aim at (object/cover-as-hero, editorial restraint). Works in Progress supplies the editorial grid; Collab Fund supplies the manifesto-hero + mark-field trust device.
